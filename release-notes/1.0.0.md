## What "stable" means

Starting now, [SemVer 2.0.0](https://semver.org/) applies fully:
- **Patch** (1.0.x) — bug fixes, no API changes
- **Minor** (1.x.0) — new commands or flags, backwards compatible
- **Major** (2.0.0) — breaking CLI changes (rare; will be telegraphed via deprecation in a prior minor)

The public surface contract is documented in [`RELEASE.md`](../RELEASE.md) §1.
