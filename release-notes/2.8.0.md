# 2.8.0 — measured font metrics for `cascade-words`

Draft release notes. The real CapCut calibration and visual render gate remain
pending before this release can be called validated.

## Highlights

- `cascade-words` now wraps sentences from measured OpenType widths, including
  spaces, and places each word using measured line prefixes.
- `--font <name|resource_id>` resolves catalogue-first and can fall back to a
  readable current draft with `--drafts <dir>`.
- `--clone-style` remains available when the guide caption has a readable,
  linear font style. An explicit `--font` overrides only the cloned font
  identity; cloned decorations and size remain in effect.
- Generated text materials receive the same font identity in their rich-text
  content and CapCut compatibility mirrors.

## Breaking change

`--max-chars` is removed. The parser rejects it explicitly. Migrate callers to
`--font` (and `--drafts` when the font is not in the catalogue), or use a valid
`--clone-style`; line wrapping is now derived from measured font widths.

## Runtime dependency

This release adds `fontkit` as the first production runtime dependency. It uses
OpenType `font.layout()` and `xAdvance` positions so kerning and shaping are
included in measurements. The font path must exist, be readable, and parse as a
supported font before the draft is mutated.

## Size and validation rules

The effective font size is selected in this order: explicit `--font-size`,
cloned style size, `material.font_size`, then `15`. Non-linear/unsupported
cloned styles and non-zero letter spacing fail fast until separately validated.

## Migration

Replace commands such as:

```text
capcut-david cascade-words <draft> cards.json --guide-track sentence --max-chars 15
```

with, for example:

```text
capcut-david cascade-words <draft> cards.json --guide-track sentence --font Rubik --drafts <drafts-dir>
```

or:

```text
capcut-david cascade-words <draft> cards.json --guide-track sentence --clone-style
```

## Validation status

Automated shaping, wrapping, mutation-safety and CLI tests are covered. A real
CapCut/cutcli probe is still required to measure and document the engine-specific
scale and to approve the final visual alignment. See
[`docs/cascade-words-font-calibration.md`](../docs/cascade-words-font-calibration.md).
